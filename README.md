# Landing page — Dra. Patrícia de Oliveira

Prévia local para captação de avaliações via WhatsApp, com identidade inspirada em pele, precisão clínica e naturalidade.

## Executar

1. Rode `npm run dev`.
2. Acesse `http://localhost:3006`.

## Imagens da prévia

Foram usadas fotografias públicas do Instagram profissional informado pelo cliente. O retrato e a cena da clínica foram restaurados para reduzir a compressão da rede social e estão armazenados localmente em `public/images`.

Antes da publicação comercial, confirmar autorização final de uso e, se possível, substituir pelas fotografias originais em alta resolução.
